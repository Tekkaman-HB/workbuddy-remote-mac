# 远程接口与功能范围

当前版本：WorkBuddy Remote 0.3.9。范围依据是 WorkBuddy 5.9.3 的远程命令绑定表、独立通道互操作结果，以及当前已接入的客户端实现。这里的“保留”不表示原版所有相关页面均已复刻。

执行历史读取恢复：详情最多三路并发，已完成详情继续缓存；切换设备或任务后停止启动旧队列。列表失败保留已有记录，首次读取失败显示重新读取入口，成功后清除历史错误提示。原生白名单只读调用遇到通道断开、发布网络故障/超时/502~504、凭证网络故障/超时时最多重试一次；业务拒绝直接返回。发送、配置、删除和产物定位不会自动重发。通道层自身不重发，已收到可信回包时以实际回包为准。账号、设备及凭证 HTTP 请求设 15 秒超时。

二级页保持能力边界：搜索只过滤已读任务标题/空间；快捷键筛选只读，三种主题与字体沿用客户端设置。模型只展示已有元数据，设备复用在线连接；目录本地筛选，不增加市场安装或远端系统设置写入。视觉证据及差异见同目录《界面复刻验收》。

执行过程按返回内容展示：远端 edge-sync 的工具投影会移除原始输入/输出等字段，仅保留名称、状态及部分摘要。本客户端不补造被裁剪的详情；无详情步骤不显示空折叠，可用摘要/参数/结果才可展开，工具行不提供执行或重试操作。

## 保留的远端能力

| 功能 | 接口依据 | 界面范围 |
| --- | --- | --- |
| 登录、发现设备、连接 | `/console/accounts`、`/console/as/conversation-sync/devices/online`、`/edge-cloud/credentials` | 账号登录、仅在线设备选择、连接恢复 |
| 任务列表与历史 | `wb:conversations:list/get/requests/markRead` | 侧栏、分页历史、富文本消息 |
| 新建、发送、停止 | `wb:conversations:create/sendPrompt/cancel` | 文本输入、续聊、停止按钮 |
| 重命名、置顶、归档、删除 | `rename/pin/unpin/archive/delete` | 任务菜单；归档、删除有对象确认 |
| 模型 | `wb:models:list/customs`、`configSetModel` | 内置/自定义分组与当前/新任务模型选择 |
| 专家 | `wb:experts:list`、`configSetExpert` | 专家目录、任务专家选择 |
| 工作/计划/问答模式 | `configSetMode` | 模式菜单 |
| 当前任务权限 | `configSetPermissionMode` | 当前任务权限选择；扩大权限先确认 |
| 工作空间 | `wb:workspaces:list`、新建参数 `cwd` | 浏览空间、创建任务前选择空间 |
| 技能与连接器目录 | `wb:skills:installed`、`wb:connectors:list` | 实际条目、描述及已有元数据的只读卡片 |
| 任务文件 | `wb:artifacts:list/get/locate` | 点击文件引用/列表，右侧预览并保存原文件；定位须先确认腾讯网盘上传与分享 |
| 定时任务 | `wb:automations:list/listRecords/getRecordDetail` | 身份聚合、日期分组的执行结果/文件卡片、分页/展开和打开执行会话 |

任务命令的缩写均指 `wb:conversations:` 前缀。会话权限值为 `fullAccess` / `bypassPermissions`，专家参数为 `{id}`。

## 能力探测

每次连接设备后，以并发只读请求检查模型、自定义模型、工作空间、专家、技能、连接器、定时任务。存在任务时，也检查任务文件接口。只有调用成功且返回可识别列表的能力才显示入口；空列表是有效结果，不等于不支持。

读取失败、方法不支持、权限拒绝或返回结构无法识别时均隐藏对应入口。这表示本次连接不能使用该能力，不据此认定服务永久不支持；重新连接会重新探测。切换设备先清空上台设备的能力结果。诊断期只采集状态码和结构字段名，不记录目录正文或凭证；临时诊断入口已在定位后移除。

写操作依据绑定表和已实现参数接入，不使用写请求做无副作用的能力探测。真实独立任务已验证创建和两轮发送；重命名、置顶、归档、删除及配置参数有实现与自动回归，未对用户业务任务做写入测试。

## 已移除的入口

- 助理管理、资料库、账号消息通知、应用发现和冗余“更多”导航。
- 控制端附件上传、语音输入、未实现的 `@` 上下文和 `/` 补全提示。
- 个人主页、套餐积分、个性化、记忆与进化、智能体管理、助理、对话流、数据导入与数据管理设置。
- 账号菜单里的记忆、意见反馈和账户官网跳转占位入口。
- 定时任务创建/修改、技能安装/执行配置、连接器授权/安装管理的操作入口。
- 完整文件编辑器、浏览器、终端、分享和未接入的专用审批操作。

部分扩展命令在原版绑定表中存在，但未接入当前客户端；没有因其存在而摆放空按钮，也没有将“去远端操作”的说明弹窗当成功能。

## 本地能力

搜索、筛选、复制、草稿、主题、字号和快捷键在客户端本地工作，保留这些功能不依赖远端管理接口。

## 验证

- 自动测试验证：接口拒绝时隐藏目录入口，设置页只列受支持项目，技能目录展示只读卡片，原有发送、草稿和富文本边界继续通过。
- 实机新建独立任务完成两轮同标记回复，任务总数从 196 增至 197，工作空间从 26 增至 27。没有修改现有业务会话。

## 实机探测与大目录修复

本次 Mac mini 的模型、工作空间、专家、技能、连接器、定时任务和任务文件七类只读探测全部成功。专家目录实际显示 95 个可选项；设置仅保留通用、外观、快捷键、模型和设备连接。

最初专家与连接器返回 `INVALID_CHANNEL_MESSAGE:INVALID_ENVELOPE`，不是接口缺失。129 片乱序回包回归复现原型的 128 片上限问题。修复后允许最多 1024 片、单条 32 MiB，所有未完成重组数据总量限制为 64 MiB；验签、密钥版本和其他结构校验保持执行。原始真实探测从失败转为全部通过。

当前共 29 项自动测试通过，含接口裁剪和大目录回包回归。

## 模型与工作空间显示

模型专用只读通道还提供 `wb:models:customs`。原版远程投影删除 `apiKey`；当前原生桥进一步仅允许模型 ID、名称、厂商及状态等展示字段进入 UI，不传递端点、自定义头和密钥。模型管理仍在远端 WorkBuddy 完成。

自定义模型用真实已发布 ID 与原始配置 ID（必要时对应已发布 `custom-local:` 或 `custom:` 前缀）合并，避免重复；配置中有条目但未出现在已发布目录时仅禁用展示，不猜测可执行 ID。模型菜单打开时重新读取两个目录，刷新失败提供重试。

未选择模型时显示“选择模型”，表示新任务创建时采用远端配置；不把产品列表中的默认标识误认成远端用户当前首选模型。选定模型或读取会话配置后显示具体模型名称。

工作空间优先使用自定义名称，否则展示路径末级目录；副行以 …/父目录/末级目录缩短共同前缀，悬停查看完整路径，搜索同时匹配名称与路径。筛选仅改变显示，点击仍使用原始目录索引与路径创建任务。

证据：本机 WorkBuddy 5.9.3 edge-sync 的 models/customs 绑定及投影、DesktopModelsRepo、产品自定义模型前缀处理；[官方多端协同](https://www.workbuddy.cn/docs/workbuddyapp/features/Multidevice)明确支持远程选择自定义模型且不展示密钥。

## 产物获取边界（0.3.7）

静态检查 WorkBuddy 5.9.3 的 edge-sync 绑定：远程 `wb:artifacts:locate` 遇到本地文件会调用 `wb:netdrive:uploadByFilePath`，参数 `createShare: true`，然后返回 downloadUrl/shareUrl。这不是纯只读元数据操作。按用户要求，点击指定附件后直接校验归属并获取预览，不再弹出二次确认。列表展示、引用匹配及能力探测不会定位或上传文件；页面普通 RPC 无法开启定位权限。

原生端重新读取当前任务产物列表，按官方 artifactId 校验归属；不按消息中的绝对路径读取远端文件。同名引用只展示列表供选择。切换任务、设备或退出会关闭预览，异步旧结果由版本序号和目标设备校验丢弃。

下载使用无 Cookie/凭证的临时 HTTPS 会话，禁止重定向到 HTTP，超过 100 MB 取消。HTML 使用无原生桥、无账号 Cookie 的临时 WebKit，并放在不授予 same-origin 的脚本沙箱；允许列明的图表 CDN，禁止外部 fetch/XHR、表单和任意子框架。原始字节仅缓存在内存，保存时不改写。最近缓存按设备、任务、产物 ID 与更新时间区分；切换设备/退出清空。

官方交互依据：[多端协同](https://www.workbuddy.cn/docs/workbuddyapp/features/Multidevice)、[任务结果](https://www.workbuddy.cn/docs/workbuddy/Results)。预览不是原版完整编辑器，不含编辑、发布分享管理或文件夹资源打包。

## 已读状态（0.3.9）

官方 edge-sync 的 REMOTE_WB_METHOD_BINDINGS 将 `wb:conversations:markRead` 列为 localConversationMethod，首参数为本地 conversationId。原生白名单按此接入；该动作修改阅读元数据，不发送任务消息，不作为只读瞬断重试方法。

普通会话在历史成功展示后提交已读；聚合定时任务在当前批次记录和详情成功读取后，对打开时已知的已有执行会话分批确认（最多三路）。历史/详情读取失败时不确认；新出现的执行会话不在原批次中。后台轮询不自动确认未被查看的内容。

回执成功后更新本地侧栏，并在内存保存会话活动版本，仅抑制相同活动版本的迟到未读列表。后续活动仍可显示未读；切换设备清空回执，重启以远端已读状态为准。回执失败保留绿点并提示重新打开重试，后台再次尝试有30秒间隔。进行中标记保持其原语义，不因阅读而隐藏。

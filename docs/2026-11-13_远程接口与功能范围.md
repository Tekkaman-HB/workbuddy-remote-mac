# 远程接口与功能范围

当前版本：WorkBuddy Remote 0.2.1。范围依据是 WorkBuddy 5.9.3 的远程命令绑定表、独立通道互操作结果，以及当前已接入的客户端实现。这里的“保留”不表示原版所有相关页面均已复刻。

## 保留的远端能力

| 功能 | 接口依据 | 界面范围 |
| --- | --- | --- |
| 登录、发现设备、连接 | `/console/accounts`、`/console/as/conversation-sync/devices/online`、`/edge-cloud/credentials` | 账号登录、设备选择、连接恢复 |
| 任务列表与历史 | `wb:conversations:list/get/requests` | 侧栏、分页历史、富文本消息 |
| 新建、发送、停止 | `wb:conversations:create/sendPrompt/cancel` | 文本输入、续聊、停止按钮 |
| 重命名、置顶、归档、删除 | `rename/pin/unpin/archive/delete` | 任务菜单；归档、删除有对象确认 |
| 模型 | `wb:models:list`、`configSetModel` | 模型列表与当前/新任务模型选择 |
| 专家 | `wb:experts:list`、`configSetExpert` | 专家目录、任务专家选择 |
| 工作/计划/问答模式 | `configSetMode` | 模式菜单 |
| 当前任务权限 | `configSetPermissionMode` | 当前任务权限选择；扩大权限先确认 |
| 工作空间 | `wb:workspaces:list`、新建参数 `cwd` | 浏览空间、创建任务前选择空间 |
| 技能与连接器目录 | `wb:skills:installed`、`wb:connectors:list` | 实际条目、描述及已有元数据的只读卡片 |
| 任务文件 | `wb:artifacts:list/get` | 任务产出列表及文件信息；有文本内容时显示文本 |
| 定时任务 | `wb:automations:list` | 只读任务列表 |

任务命令的缩写均指 `wb:conversations:` 前缀。会话权限值为 `fullAccess` / `bypassPermissions`，专家参数为 `{id}`。

## 能力探测

每次连接设备后，以并发只读请求检查模型、工作空间、专家、技能、连接器、定时任务。存在任务时，也检查任务文件接口。只有调用成功且返回可识别列表的能力才显示入口；空列表是有效结果，不等于不支持。

读取失败、方法不支持、权限拒绝或返回结构无法识别时均隐藏对应入口。这表示本次连接不能使用该能力，不据此认定服务永久不支持；重新连接会重新探测。切换设备先清空上台设备的能力结果。诊断期只采集状态码和结构字段名，不记录目录正文或凭证；临时诊断入口已在定位后移除。

写操作依据绑定表和已实现参数接入，不使用写请求做无副作用的能力探测。真实独立任务已验证创建和两轮发送；重命名、置顶、归档、删除及配置参数有实现与自动回归，未对用户业务任务做写入测试。

## 已移除的入口

- 助理管理、资料库、账号消息通知、应用发现和冗余“更多”导航。
- 控制端附件上传、语音输入、未实现的 `@` 上下文和 `/` 补全提示。
- 个人主页、套餐积分、个性化、记忆与进化、智能体管理、助理、对话流、数据导入与数据管理设置。
- 账号菜单里的记忆、意见反馈和账户官网跳转占位入口。
- 定时任务创建/修改、技能安装/执行配置、连接器授权/安装管理的操作入口。
- 完整文件编辑器、浏览器、终端、分享和未接入的专用审批操作。

部分扩展命令在原版绑定表中存在，但未接入当前客户端；没有因其存在而摆放空按钮，也没有将“去远端操作”的说明弹窗当成功能。

## 本地能力

搜索、筛选、复制、草稿、场景提示词、主题、字号和快捷键在客户端本地工作，保留这些功能不依赖远端管理接口。

## 验证

- 自动测试验证：接口拒绝时隐藏目录入口，设置页只列受支持项目，技能目录展示只读卡片，原有发送、草稿和富文本边界继续通过。
- 实机新建独立任务完成两轮同标记回复，任务总数从 196 增至 197，工作空间从 26 增至 27。没有修改现有业务会话。

## 实机探测与大目录修复

本次 Mac mini 的模型、工作空间、专家、技能、连接器、定时任务和任务文件七类只读探测全部成功。专家目录实际显示 95 个可选项；设置仅保留通用、外观、快捷键、模型和设备连接。

最初专家与连接器返回 `INVALID_CHANNEL_MESSAGE:INVALID_ENVELOPE`，不是接口缺失。129 片乱序回包回归复现原型的 128 片上限问题。修复后允许最多 1024 片、单条 32 MiB，所有未完成重组数据总量限制为 64 MiB；验签、密钥版本和其他结构校验保持执行。原始真实探测从失败转为全部通过。

当前共 15 项自动测试通过，含接口裁剪和大目录回包回归。

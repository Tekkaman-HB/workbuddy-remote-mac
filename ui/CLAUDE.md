# ui/
> L2 | 父级: ../CLAUDE.md

成员清单
index.html: WebKit 本地页面骨架，CSP 禁止远程脚本与页面网络请求。
styles.css: 对照本机 WorkBuddy 5.9.3 的颜色、尺寸、侧栏与首页样式；顶部工具栏共享高度与上下内边距，折叠后避让原生窗口控制区。
chat.css: 原版正文/执行折叠、自动化日期/结果/文件卡片、计划标签和下次运行时间及输入区样式。
panels.css: 菜单、设置、文件面板及响应式布局。
motion.css: 最后一层视觉精修、统一图标、焦点、SVG 下拉箭头与减少动态效果规则。
motion.js: 后台直接展示内容，避免 WebKit 暂停在透明首帧；可中断弹层/侧栏/布局位移，统一取消并恢复焦点。
app.js: 顶部空白区原生拖动，控件/右键排除；自动化展开、文件和执行会话路由；输入/键盘及已有菜单动作，预览时收起并恢复侧栏。
controller.js: 设备连接、只读能力探测、按自动化 ID 读取执行历史/分页详情缓存；归属/代次校验、展开位置保留及执行会话产物匹配；模型、草稿与普通任务协调。
tasks.js: 纯任务投影，自动化按 ID 聚合、任务/空间/助理/归档分流、普通同名会话保留；分钟/小时/日历天/月日与真实计划标签。
automations.js: 只读执行历史的日期、结果/文件卡片、展开状态、下一次运行及读取失败反馈；按实际溢出显示渐隐/展开并响应窗口尺寸，复用 Markdown 净化。
view.js: 身份聚合后的完整侧栏、右侧未读/运行状态与真实时间；自动化计划标题与历史入口；普通首页/聊天和稳定折叠 DOM。
panels.js: 无搜索框的模型分组选择、可搜索的双行工作空间选项、仅在线设备菜单、账户与精简设置及原生主题同步，去除常驻解释文字并保留状态、错误与确认；目录和定时任务按能力开放只读展示；文件引用与文件列表交给原生预览。
transcript.js: 转录语义、执行过程/正文分层、真实状态耗时及工具中文摘要。
preview-theme.js: 隔离报告的深色阅读与原样恢复；调整明暗表面、文字和 ECharts 坐标/图例，保留数据语义色；主题消息仅来自父框架。
artifacts.js: 将内联文件名/本地文件链接转为预览按钮，按当前产物列表匹配，保留同名歧义，不读取消息指定的路径。
render.js: 可点击产物引用、Markdown 净化、默认收起的执行过程、正文、工具详情与回复元数据。
catalog.js: 内置与自定义模型合并、已发布 ID 对应、显示名称、工作空间末级名称与精简路径提取。
state.js: 原生 Promise 桥、列表识别、会话合并、设备能力及自动化历史/展开状态，统一 tasks 投影入口。
icons.js: 统一 24 格坐标与 1.65 线宽的 SVG 图标，装饰图形不参与键盘焦点。
assets/ - 独立 Remote 应用图标和界面标识。

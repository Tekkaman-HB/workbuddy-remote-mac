# ui/
> L2 | 父级: ../CLAUDE.md

成员清单
index.html: WebKit 本地页面骨架，CSP 禁止远程脚本与页面网络请求。
styles.css: 对照本机 WorkBuddy 5.9.3 的颜色、尺寸、侧栏与首页样式。
chat.css: 聊天消息、富文本和输入区样式。
panels.css: 菜单、设置、文件面板及响应式布局。
motion.css: 最后一层视觉精修、统一图标、焦点、SVG 下拉箭头与减少动态效果规则。
motion.js: 可中断的弹层显隐、内容入场、侧栏切换和布局位移；统一动画取消，恢复可见控件焦点。
app.js: 页面入口、已接入的菜单动作、输入与键盘路由；不包含功能占位动作。
controller.js: 设备连接、只读能力探测、分页读取、草稿、任务写入和轮询协调。
view.js: 精简远程首页、侧栏、任务标题、SVG 下拉控件、输入区与按消息复用 DOM 的历史渲染。
panels.js: 设备、模型、工作空间、账户与精简设置，去除常驻解释文字并保留状态、错误与确认；目录、文件和定时任务按能力开放只读展示。
render.js: Markdown 净化、消息块与工具结果展示。
state.js: 原生 Promise 桥、列表结构识别、会话合并及设备能力状态。
icons.js: 统一 24 格坐标与 1.65 线宽的 SVG 图标，装饰图形不参与键盘焦点。
assets/ - 独立 Remote 应用图标和界面标识。

# ui/
> L2 | 父级: ../CLAUDE.md

成员清单
index.html: WebKit 本地页面骨架，CSP 禁止远程脚本与页面网络请求。
styles.css: 对照 WorkBuddy 5.9.3 的主题/侧栏/首页；1440px 阅读上限与 32/16/12px 响应式边距，顶部工具栏统一高度并避让原生控制区。
chat.css: 轻量过程行、14px 工具图标/10px 悬停箭头、思考细线/详情卡片；自适应正文与输入区、自动化结果及横向自动换行的 240px 附件卡片。
panels.css: 原版搜索/设置窗口尺寸、关闭图标独立 8px 并裁剪、图标导航、搜索框、主题卡片、快捷键表、主区域目录与响应式布局。
motion.css: 统一图标、焦点、SVG 下拉箭头与减少动态效果；二级页面字号/间距由 panels.css 维护。
motion.js: 后台直接展示内容并取消旧布局动画，避免 WebKit 暂停在透明/位移中间帧；可中断弹层/侧栏/布局位移，统一取消并恢复焦点。
app.js: 顶部历史自动加载和上滑重试，顶部空白区原生拖动，控件/右键排除；自动化展开、文件和执行会话路由；输入/键盘及已有菜单动作，预览时收起并恢复侧栏。
controller.js: 账号发现与原生认证状态对齐，认证失败清理、网络失败保留登录； 阅读成功后调用远端 markRead，同版本回执覆盖迟到未读列表，新活动保留未读；自动化按已打开任务的执行会话批次确认，失败保留绿点、后台不自动确认； 到顶历史单飞、轮询后补页与失败重试，设备连接/能力探测；按自动化 ID 读取历史/缓存详情（最多三路），失败保留记录、恢复清除提示；归属/代次校验、阅读位置、产物/模型/草稿协调。
tasks.js: 同版本已读回执归一及纯任务投影，自动化按 ID 聚合、任务/空间/助理/归档分流、普通同名会话保留；分钟/小时/日历天/月日与真实计划标签。
automations.js: 只读执行历史的日期、结果/文件卡片、展开状态、下一次运行及首读/详情失败重试入口；按实际溢出显示渐隐/展开并响应窗口尺寸，复用 Markdown 净化。
view.js: 身份聚合后的完整侧栏、右侧未读/运行状态与真实时间；自动化计划标题与历史入口；普通首页/聊天和稳定折叠 DOM。
popover-position.js: 按锚点/内容/视口计算方向与限高，列表增高自动翻转、窄窗口保持安全边距。
panels.js: 未登录账号菜单直接登录、已登录未连接与零在线设备状态区分； 本地任务/空间分组搜索与键盘导航；图标设置导航、快捷键筛选、三种主题与原生外观同步；异步内容/锚点尺寸/窗口变化后重定位的模型单行分组、双行空间选项、在线设备与账户；目录按能力只读、主区整页展示与本地筛选，文件交给原生预览。
transcript.js: 转录分层与真实耗时、工具中文动作/类型图标/文件名/状态；判断已有详情，保留未知名称，不猜测被裁剪的调用。
preview-theme.js: 隔离报告的深色阅读与原样恢复；调整明暗表面、文字和 ECharts 坐标/图例，保留数据语义色；主题消息仅来自父框架。
artifacts.js: 将内联文件名/本地文件链接转为预览按钮，按当前产物列表匹配，保留同名歧义，不读取消息指定的路径。
render.js: Markdown 净化、默认收起的过程与正文；思考轻量折叠、工具真实摘要/参数结果详情，无详情显示非交互行；产物引用与回复元数据。
catalog.js: zh/en 目录名称/说明归一，被目录卡片与专家标签共用；内置/自定义模型合并、已发布 ID 对应、空间名称和精简路径。
history-scroll.js: 共享顶部加载/失败/结束提示、到顶与上滑事件、按可见记录恢复阅读锚点。
state.js: 明确认证状态、统一账号清理与账号名称； 历史分页/失败状态、网络阶段错误文案、原生 Promise 桥、列表识别、会话合并、设备能力及自动化历史/展开状态，统一 tasks 投影入口。
icons.js: 设置/搜索/目录及通用 SVG 图标，统一 24 格坐标与 1.65 线宽，装饰图形不参与键盘焦点。
assets/ - 独立 Remote 应用图标和界面标识。

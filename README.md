# WorkBuddy Remote for Mac

**用一款独立的 Mac App，远程连接并继续另一台 Mac 上的 WorkBuddy 本地任务。**

控制端无需安装 WorkBuddy，无需开放平台应用或密钥。

## 这是什么

WorkBuddy Remote 是一个**非官方、独立实现**的 macOS 客户端：

- 🔌 **自主登录** —— App 内置 WebKit 会话完成官方网页登录，凭证只留在登录窗口
- 🖥️ **远程接管** —— 发现并连接同账号下的另一台 Mac，读取完整分页任务列表
- 💬 **继续对话** —— 新建任务、文字续聊、停止、模型/专家/模式选择、远端工作空间选择
- 📄 **报告预览** —— 点击文件名在右侧查看 HTML 报告、展开阅读并保存原文件
- 🔒 **凭证隔离** —— 内置 UI 不加载远程脚本，登录令牌与通道密钥永不传入 UI 层

通信经过腾讯服务中转，任务实际在远端 Mac 上执行。

## 快速开始

**运行要求**：macOS 13+（运行 App 无其他依赖，所有页面与脚本均已内置）

1. 打开 `dist/WorkBuddy Remote.app`（构建方式见[下方](#构建与测试)）
2. 点左下角设备图标 → **使用 WorkBuddy 账号登录**，在官方网页完成登录和账号选择
3. 点登录窗口底部 **登录完成，读取设备**，返回 App 选择目标 Mac
4. 目标 Mac 必须运行 WorkBuddy，并开启「允许移动端连接此设备」
5. 点击侧栏任务查看历史；`Enter` / `⌘Enter` 发送，`Shift Enter` 换行；下次启动会尝试恢复上次设备

**快捷键**：`⌘K` 搜索任务 · `⌘N` 新建任务 · `⌘,` 打开设置。悬停任务行的「…」可重命名、置顶、归档或删除，删除和扩大任务权限会先确认。

## 构建与测试

构建需要 Xcode Command Line Tools 与 Node.js 22+：

```sh
npm ci --ignore-scripts
npm test            # 自动测试
zsh build.command   # 产出 dist/WorkBuddy Remote.app
```

## 架构与安全边界

```
┌─────────────────────────────────────────────────┐
│              WorkBuddy Remote.app               │
│                                                 │
│  MacApp/   AppKit 窗口 · WebKit 自主登录         │
│      │                                          │
│      ├── 登录 WebKit 会话（唯一持有凭证）          │
│      │                                          │
│      └── 受限原生桥（无登录态、无通道密钥）        │
│              │                                  │
│  ui/       独立页面 · DOMPurify 净化渲染          │
│              │                                  │
│  lib/wire.mjs  原创加密通道 ──► 腾讯服务中转       │
│                                   │             │
└───────────────────────────────────▼─────────────┘
                          远端 Mac（运行 WorkBuddy）
```

| 目录 | 职责 |
| --- | --- |
| [lib/](lib/) | 通道凭证装载、SDK 协议实现与远程命令验证 |
| [MacApp/](MacApp/) | AppKit 原生窗口、受限 UI 桥和 WebKit 自主登录 |
| [ui/](ui/) | 独立实现的界面，净化消息渲染 |
| [tests/](tests/) | 协议边界与凭证保护自动测试 |
| [docs/](docs/) | 技术验证与协议边界报告 |

**安全设计要点**：

- 凭证仅存在于登录 WebKit 会话；内置页面通过受限原生桥调用，不接收登录令牌或通道密钥
- HTML 报告预览运行在**无登录态、无原生桥**的沙箱中，仅允许常见图表 CDN 与内联脚本
- 点击附件即获取并预览；官方文件接口可能经腾讯网盘上传/分享传回，原文件仅做内存缓存
- 只读接口只提供只读页面；连接时探测目录接口，失败的能力不显示入口

## 当前能力

- 自主登录、发现设备、连接另一台 Mac，读取完整分页任务列表
- Markdown、表格、代码复制、图片、思考与工具折叠内容；加载更早历史
- 新建任务、文字续聊、停止、模型/专家/模式选择、远端工作空间选择
- 账号菜单、任务搜索与筛选、任务文件目录、隔离预览及原文件保存、定时任务只读列表
- 本客户端的主题和消息字体大小设置
- 独立双屏应用图标与侧栏标识；菜单、弹层和侧栏动效；遵循系统「减少动态效果」
- 历史每 2 秒刷新，任务列表每 30 秒刷新；稳定消息复用 DOM、保留阅读位置；发送失败保留草稿，不自动重发

<details>
<summary><b>已知限制</b></summary>

- 已移除语音、控制端附件上传、资料库/助理管理、通知、账户套餐和未接入的主机设置

- 未对用户业务任务做删除、归档或权限变更的实机写入测试；长期睡眠/切网恢复仍需继续验证
- App 仅本机签名，未做 Developer ID 公证，当前构建为本机 CPU 架构
